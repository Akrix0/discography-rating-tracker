# Universal Discography & Rating Tracker

Універсальний локальний вебзастосунок для автоматичного збирання, прослуховування (через офіційні Spotify Embeds) та незалежного оцінювання дискографій будь-яких музичних виконавців із локальною базою даних **SQLite**.

При першому запуску автоматично завантажується повна верифікована дискографія **Mother Mother** (62 релізи, 246 композицій), а якщо у вас уже є оцінки в окремій версії `Mother-Mother-Rating` — вони автоматично переносяться без змін оригіналу.

---

## Можливості мульти-артист платформи

- **Додавання будь-якого виконавця в 1 дію**: введіть назву гурту або вставте посилання на профіль у Spotify (`https://open.spotify.com/artist/...`).
- **Вибір глибини імпорту**: чекбокси перед збором дозволяють обрати, чи додавати Sped Up / Slowed / Acoustic / Demo версії, Live-записи, Ремікси та Deluxe-видання.
- **Прокручуваний перемикач виконавців у шапці**: миттєвий перехід між доданими гуртами або в глобальний хаб зі статистикою.
- **Мої виконавці та Глобальний крос-артист рейтинг** (`/artists`): картки всіх гуртів із прогресом, кнопка «Перевірити нові релізи», видалення, а також спільний топ пісень, топ альбомів та рейтинг виконавців.
- **Тумблер «Приховати альт-версії / Live / Ремікси»**: приховує другорядні версії пісень одним кліком у каталозі.
- **Гібридний режим Spotify**: працює одразу без ключів (публічний Spotify + MusicBrainz + Deezer + Apple/iTunes), а за бажанням у розділі **«Налаштування»** можна додати власні `Spotify Client ID` і `Client Secret` для 100% покриття будь-яких виконавців.
- **Два незалежні рівні оцінювання (0–100)** із миттєвим автозбереженням (`Saving…` / `Saved` / `Error`) і текстовими нотатками.

## Швидкий запуск на Windows

### Варіант 1 — Одним кліком
Двічі клацніть файл **`start-app.bat`** у папці `Discography & Rating Tracker`.

### Варіант 2 — Через термінал
```powershell
cd "C:\Users\Admin\Desktop\Discography & Rating Tracker"
npm install
npm run dev
```
Відкрийте у браузері: [http://localhost:5173](http://localhost:5173).

### Production-режим
```powershell
npm run build
npm start
```
Сайт та API будуть доступні на [http://localhost:3001](http://localhost:3001).
